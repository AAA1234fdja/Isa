# Security

ISA includes experimental execution, workspace editing and credential-related
features. Read the security limitations and platform-specific warnings in the
README before enabling them. Do not expose the local server to untrusted
networks or assume an experimental feature provides isolation.

## Reporting a vulnerability

Please avoid posting exploit details, credentials or sensitive workspace contents
in a public issue. Contact the repository owner privately; if GitHub's private
vulnerability reporting is enabled for this repository, use its Security tab.
If no private reporting channel is available, ask the owner for one without
sharing sensitive details publicly. Include affected version or commit, platform,
reproduction steps and impact once a private channel is established. No response
time or supported-version commitment is currently specified.
